Reel framework (IG-native conversion)

Every reel posted to @thelawncarelife runs the same architecture so the bio router stays consistent:

[0:00-0:03 - hook from the bank above]
[0:03-0:25 - the value - one tip, one demonstration, one teach]
[0:25-0:30 - one-line CTA: "Link in bio for the Letter / Q+A / cohort"]
[Caption - 1-2 sentence repeat of CTA + tag for source attribution]

Every reel routes to the bio router. Bio router presents three paths: 1. The Lawn Care Letter ($99) - default for new viewers 2. Q+A live (YouTube) - free, builds trust 3. Mentorship application - for academy graduates only

Q+A drip system

Q+A live shows continue every Tuesday. After each show:

  1. Within 24 hours: uploaded to YouTube as the standard Q+A replay (current cadence - keep)
  2. Within 48 hours: 3-5 short-form clips pulled from the Q+A and posted to IG @thelawncarelife + Facebook @jasonlawncarelife (NEW - current process leaves the long-form to do all the work)
  3. Within 7 days: Q+A added to the Insider membership archive, tagged by month + topic + warm-season operator stage (NEW - turns the back-catalogue into a member benefit)

The same hour of filmed Q+A content powers four surfaces: live show, YouTube replay, IG / Facebook short-form clips, Insider archive. No new filming required. The repurposing is the install.

Podcast catalog brief

Jason has appeared as a guest on multiple green-industry podcasts (Untrapped Podcast with Keith Kalfas, Lawn Care Live with Paul Jamison, others). The work here is light - not launching a new podcast, just packaging the existing guest catalog so it converts.

  • Pull every public guest appearance into one place (a /podcast tile on lawncarelife.com)
  • For each appearance, extract the 3-5 best clips (60-90 seconds each)
  • Repurpose clips as IG / YouTube shorts with bio-router CTA
  • Cite host + show + episode date - never re-host the full episode without permission
